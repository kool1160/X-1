## Current engineering focus

The next release is blocked by component selection, not fabrication capability. The immediate work is to compare complete guide-and-drive packages using exact dimensions and delivered cost, then model the selected hardware before producing Rev B cut files.

## Rev B entry criteria

- Exact Y guide model and length selected
- Exact X guide model and length selected
- X/Y drive architecture selected
- Actual drive hardware selected
- Motor/driver strategy selected
- Z guide and drive selected
- Usable travel calculated from physical hardware
- Critical components measured or supported by verified drawings
