## Current engineering focus

The active phase is architecture and component freeze. The project must select exact guide, drive, motor/driver, Z-axis, and THC hardware/firmware boundaries before Rev B manufacturing outputs are released.

THC is a required production subsystem. Fixed-height cutting is an intermediate commissioning test only.

## Rev B entry criteria

- exact Y guide model and length selected;
- exact X guide model and length selected;
- X/Y drive architecture and actual hardware selected;
- motor/driver strategy selected;
- Z guide and drive selected;
- usable travel calculated from physical hardware;
- THC architecture selected and control/interface boundary defined;
- X-1 operator-software communication path proven;
- critical components measured or supported by verified drawings;
- decisions and requirements updated with no control-critical or dimension-critical ambiguity.
