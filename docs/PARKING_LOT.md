# X-1 Parking Lot

This file preserves worthwhile ideas without allowing them to interrupt the active phase.

An item in this file is **not approved work**. Do not research deeply, design, code, purchase, or add it to the current release unless it is moved into `PROJECT_STATUS.md` through a deliberate scope change.

## Parked platform ideas

- Mesa/LinuxCNC/QtPlasmaC controller migration
- EtherCAT motion and I/O architecture
- complete custom motion controller
- controller-board cloning
- alternate non-FluidNC firmware

These become active only if the Jackpot/FluidNC baseline fails a documented X-1 requirement. THC development within a controlled X-1 FluidNC fork is not parked because THC is a required subsystem.

## Parked machine expansions

- 4×8 or larger travel beyond the selected standard-component tier
- rotary tube-cutting axis
- bevel head or multi-axis torch
- drilling, routing, marking, or multi-process head
- fiber-laser machine development
- automated sheet loading or unloading

## Parked software features

- integrated CAD
- full CAM and postprocessor development
- automatic nesting
- quoting and customer-order management
- cloud accounts or remote job management
- mobile application
- AI-generated cut files or automatic process tuning
- consumable purchasing integration
- multi-machine fleet dashboard

## Parked appearance and commercial work

- final branding package
- production sales website
- customer manuals and warranty language
- product certification and commercial release
- final decorative skins before machine dimensions and guards are frozen

## Parking-lot entry format

When adding an idea, include:

- idea;
- reason it may be useful;
- trigger that would make it active;
- affected phase or subsystem;
- date added.

Do not add a deadline or active assignee while the item remains parked.
