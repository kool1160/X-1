# Released Drawings and Cut Files

This directory is for manufacturing outputs, not native CAD.

## Future contents

- released PDF fabrication drawings;
- DXF laser/plasma cut files;
- tube cut and drill tables;
- hole-coordinate tables;
- water-pan and slat-comb layouts;
- enclosure and cosmetic-skin flats;
- revision index.

## Release rule

Rev A is conceptual. Do not fabricate dimension-critical rail, block, motor, ball-nut, rack, belt, or end-support holes until exact purchased components are selected and modeled. Released files shall include a revision, material, thickness, quantity, and scale note.
