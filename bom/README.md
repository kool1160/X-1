# Bill of Materials Workspace

This directory will hold X-1 component research and released BOM revisions.

For every dimension-critical purchased component, record the manufacturer, model, supplier, quantity, delivered cost, nominal dimensions, measured dimensions, datasheet, replacement availability, and selection status.

Priority groups:

1. Y rails and blocks
2. X rails and blocks
3. X/Y drive components
4. Motors and drivers
5. Z-axis guide and drive
6. Cable chain and wiring
7. Home and probe switches
8. Torch-start relay and isolated inputs
9. Power supplies and enclosure hardware
10. Water-pan drains, slats, and service hardware

Released BOMs should separate on-hand material from purchased parts so the project cost is easy to track.
