# CAD Workspace

This directory will hold native X-1 design files.

## Planned structure

- `assembly/` - top-level SolidWorks assembly and motion studies
- `frame/` - welded tube frame and pan-support weldments
- `gantry/` - Y trucks, gantry beam, X carriage, and covers
- `z-axis/` - Z slide, torch holder, floating/probe mechanism
- `guards/` - rail, drive, cable, and pinch-point guards
- `skins/` - removable Laser X Design cosmetic panels
- `enclosure/` - electronics cabinet, backplate, and brackets

## Rules

- Model actual purchased rails, blocks, screws/racks/belts, motors, and supports before releasing mounting holes.
- Use X-1 part numbers defined in the released drawing package.
- Keep source models separate from exported DXF/PDF manufacturing files.
- Update the as-built assembly when shop changes are made.
